# 🍽️ Análisis de Datos para Restaurante Familiar (Lima, Perú)

## 📌 El Problema
El restaurante de mi madre registraba sus ventas y gastos en papel, sin una visión clara de qué platos eran realmente rentables ni qué días vendía más. Como Analista de Datos Junior, mi objetivo fue crear un sistema que le tomara menos de 3 minutos al día y le diera información accionable.

## 🛠️ Solución Implementada
Diseñé un flujo de datos de 3 capas:
1. **Captura:** Formulario de Google vinculado a Google Sheets para el registro diario.
2. **Procesamiento:** Script en Python (pandas) para limpieza de datos, normalización de textos y cálculo de ganancias.
3. **Visualización:** Dashboard en Power BI con dos vistas: una móvil (para la dueña) y una analítica (para toma de decisiones).

## 📊 Hallazgos Principales
- Se identificó que platos como el Menú del día tienen un alto volumen de ventas pero bajo margen de ganancia.
- El análisis de rentabilidad permite recomendar ajustes de precios y promociones en días de baja venta.

## 💻 Tecnologías Usadas
- **Python (pandas):** Limpieza y transformación de datos.
- **Power BI:** Modelado de datos, DAX y visualización.
- **Google Sheets:** Base de datos relacional básica.
- **Git/GitHub:** Control de versiones.
